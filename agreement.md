# Соглашение об архитектуре #

## О сервере ##

__Первоочередной задачей__ сервера является:

1. Агрегация запросов к бэкенд
2. Передача данных в клиентские компоненты

### Сервер не должен решать задачи клиентского состояния ###

## Server -> Client ##

Передача данных от сервера в клиент происходит через компоненты-адаптеры.

Например:

- MangaPageAdapter
- ChapterPageAdapter

Адаптеры не содержат бизнес логику


deviceType как props могут получать компоненты-страницы, осталньые использую selectDeviceType
